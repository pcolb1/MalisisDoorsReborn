# MalisisDoorsReborn
Issue Tracker/Wiki etc.

This source bundle contains the HBM-related source and assets included in MalisisDoorsReborn.

It includes the dedicated HBM Java source package, adapted HBM door model/texture assets, HBM sound assets, and the relevant LGPL/GPL licence and third-party notice files.

MDR-authored support files are excluded unless they contain original or adapted HBM material.
